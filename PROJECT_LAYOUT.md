# NetMon project layout

`netmonlast` is the project root. NetMon's companion projects and runtime check
apps are kept under `integrations/` so the application has one Desktop folder.

| Folder | Purpose |
| --- | --- |
| `integrations/check-apps/` | Python DoH, DNS, website-access, and route checks used by Monitoring. |
| `integrations/dpi-apps/` | Python DPI applications used by the DPI Tools app. |
| `integrations/iran-internet-monitor/` | Iran Internet Monitor source and its live data repository. |
| `integrations/network-checker/` | Network Checker source project. |
| `integrations/nova-radar/` | NovaRadar source project used as the reference for NetMon Radar. |
| `internet-monitor/` | NetMon's in-repository Iran observatory integration. |
| `third_party/NovaRadar/` | NovaRadar license and attribution notices for NetMon's adapted implementation. |

The DPI and Monitoring services default to the companion folders above. Set
`DPI_BACKEND_DIR` or `NETMON_CHECK_APPS` to override those locations.

The companion repositories were moved with their Git metadata and local changes
preserved. `integrations/iran-internet-monitor/` may contain uncommitted live
monitor data generated by its scheduled probes.
