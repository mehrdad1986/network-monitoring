       fragment  resp=8B  ("|timeout" only)  12.3s

[CMD] python3 tls_fragment.py workers.dev 443          (control)
[OUT]  single 544B 0.2s / fragment 544B 0.4s / delay 544B 0.8s
[CMD] python3 tls_fragment.py cloudflare.com 443       (control)
[OUT]  single 560B 0.2s / fragment 560B 0.4s / delay 560B 0.8s

[VERD] Controls return data in 0.2-0.8 s, so the script is correct. Splitting
       the ClientHello across two TCP writes 150 ms and 600 ms apart changes
       nothing on the blocked host. The filter REASSEMBLES the ClientHello and
       then matches. Xray "fragment: tls-clienthello" is therefore NOT a
       sufficient mitigation against this operator — that is the single most
       important practical result here.
